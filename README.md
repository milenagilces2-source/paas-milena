# PaaS (Plataforma como Servicio) – Tarea TICs

## ¿Qué es PaaS?
PaaS (Platform as a Service) es un modelo de computación en la nube que proporciona una plataforma completa para desarrollar, ejecutar y administrar aplicaciones sin tener que configurar o gestionar la infraestructura subyacente (servidores, sistemas operativos, redes, etc.). :contentReference[oaicite:2]{index=2}

## Plataforma usada para la actividad
Para esta tarea se creó una cuenta en **Glitch** o **Heroku** y se desplegó una aplicación simple en la nube.

## ¿Cómo funciona PaaS?
Un proveedor PaaS ofrece herramientas, entornos y servicios listos para que los desarrolladores puedan enfocarse en crear aplicaciones, sin preocuparse por la administración de servidores o infraestructura física. :contentReference[oaicite:3]{index=3}

## Ejemplo de implementación
Usé **Heroku** como ejemplo de PaaS y desplegué una aplicación web básica.
Heroku es una plataforma PaaS que soporta varios lenguajes de programación como JavaScript, Python, PHP, entre otros. :contentReference[oaicite:4]{index=4}

## Ventajas observadas
- No es necesario gestionar servidores ni infraestructura.
- El despliegue de aplicaciones es más rápido.
- Escalabilidad automática según demanda.
- Permite centrarse en el desarrollo del proyecto.

## Reflexión sobre los beneficios y desafíos
Los beneficios de usar PaaS son que **facilita el desarrollo y despliegue de aplicaciones sin conocimientos de administración de servidores** y permite entregar proyectos más rápido.  
Un desafío puede ser que a veces **dependes de las herramientas del proveedor**, lo que limita la personalización avanzada.
